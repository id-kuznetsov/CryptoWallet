# CryptoWallet

## Технологии

- **Swift**
- **UIKit**
- **MVVM**
- **Верстка кодом (Autolayout)**
- **URLSession** — сетевой слой
- **UserDefaults** — хранение состояния авторизации

## Реализация

### Экран авторизации с валидацией логина и пароля
- В случае ошибки показывается алерт c вариантами повторить и отменить
- Экран смещается при появлении клавиатуры
- Переключение между полями возможно с помощью кнопки **"Ввод"**
- Статус авторизации отслеживается с помощью `AuthService`

### Список криптовалют
- Отображает цену, название, изменение за 24 часа
- Загрузка осуществляется через `CoinMetricsService` (синглтон) с использованием `URLSession`
- Сортировка по умолчанию убыванию (возможен выбор по возрастанию)
- При загрузке используется `DispatchGroup`
- Используется `SnakeCaseJSONDecoder` для корректного парсинга `snake_case`

### Детальный экран монеты
- Сверстан по макету
- Используется кастомный `CustomSegmentedControl` для переключения временных интервалов

### Обработка ошибок
- Все сетевые и загрузочные ошибки перехватываются
- Для отображения используется `AlertPresenter`
